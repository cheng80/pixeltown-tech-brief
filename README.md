# 픽셀타운 기술 검토

2D 소셜 게임의 초기 20명 운영과 확장 경로를 정리한 7페이지 HTML 발표자료입니다.

[발표자료 열기](https://cheng80.github.io/pixeltown-tech-brief/)

## 사용

- 방향키로 페이지를 전환합니다.
- 전체 보기, 전체 화면, 인쇄/PDF 저장을 지원합니다.
- 이미지와 도표는 `index.html`에 포함되어 있습니다.
- 실측값과 추정값, 비용 계산 조건 및 공식 출처는 발표자료에 표시했습니다.

## 수정 및 배포

`index.html`을 수정해 `main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.
별도 의존성 설치나 빌드 과정은 필요하지 않습니다.

## 로컬 확인

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8766/`을 엽니다.

요금·서비스 한도의 확인 기준은 2026년 10월 2일입니다. 비용 예시는 실제 견적이나 수용량 보장이 아닙니다.
